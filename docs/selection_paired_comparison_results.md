# Paired fixed-truth comparison: toy event-detection selection

**Status:** first 1,800-observation run completed successfully; regression tests for the latest finite-interval implementation are still being rerun.  
**Scope:** synthetic two-host toy model only. These results are not an LVK analysis and do not validate a realistic gravitational-wave selection function.

## Design

The same simulated detected observation is passed to two inference methods: (1) the ordinary weighted host-mixture likelihood and (2) the same likelihood divided by the detection efficiency $\beta(H_0)$. Detection is generated by rejection sampling with $0<d_{\rm obs}<180$ Mpc. The prior is uniform on $50\le H_0\le90$ km s$^{-1}$ Mpc$^{-1}$; host redshifts are 0.02 and 0.04 with pre-detection weights 0.70 and 0.30; the assumed distance noise is 20 Mpc. The fixed truths are 55, 70, and 85, with 600 replicates per truth. The run used seed 20261028 and 2,001 grid points.

## Interpretation and limitations

1. The correction improved RMSE and 68% coverage at truth $H_0=55$ in this run.
2. At truth $H_0=70$, bias decreased but RMSE increased slightly and 68% coverage was already very high for both methods.
3. At truth $H_0=85$, the correction worsened RMSE and 68% coverage. This is a warning against claiming that selection normalization always improves finite-sample point estimation.
4. At 600 replicates, the approximate binomial Monte Carlo standard error for 68% coverage is $\sqrt{0.68(0.32)/600}\approx 1.9$ percentage points, and for 95% coverage is about 0.9 percentage points. Small differences in coverage should not be overinterpreted.
5. The broad distance uncertainty, two-host mixture and finite prior can dominate behavior. A proper follow-up should report paired bootstrap uncertainty for changes in bias/RMSE/absolute error, inspect prior-boundary effects, and vary threshold/noise to determine when selection normalization matters.
6. This is not a realistic GW detector model. It does not include a calibrated detection statistic, detector duty cycle, network sensitivity, source population, cosmological volume effects, or a real injection campaign.
