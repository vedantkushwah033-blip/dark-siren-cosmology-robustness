## Findings from the artifact

### 1. Posterior normalization and integration rule

Across the four saved grid/prior cases, trapezoidal posterior area on the stated prior support is 1.0 to displayed precision. In the targeted 52 km s\u207b\u00b9 Mpc\u207b\u00b9 truth case, the absolute difference between trapezoidal and Simpson-rule posterior area falls from approximately \(3.38\times10^{-6}\) at 1,001 grid points to \(8.25\times10^{-10}\) at 64,001 points. This supports numerical integration stability for this tested observation; it does not validate the likelihood assumptions.

### 2. Grid refinement matters more for the upper 95% endpoint than for the median

The targeted case uses redshifts 0.02 and 0.04, noise fraction 0.03, observed distance 119.474152 Mpc, reversed inference weights 0.3/0.7, and the same prior support. Refinement results:

| Grid points | Posterior median | Lower 68% | Upper 68% | Upper 95% |
|---:|---:|---:|---:|---:|
| 1,001 | 51.713915 | 50.514052 | 53.692477 | 60.848373 |
| 4,001 | 51.713486 | 50.513928 | 53.691714 | 60.717920 |
| 16,001 | 51.713446 | 50.513917 | 53.691638 | 60.710428 |
| 32,001 | 51.713445 | 50.513917 | 53.691634 | 60.710055 |
| 64,001 | 51.713445 | 50.513917 | 53.691633 | 60.709962 |

From 4,001 to 64,001 points, the median changes by about 0.000041 and the upper 68% endpoint by about 0.000081, while the upper 95% endpoint changes by about 0.00796 in H0 units. The 4,001-point grid is therefore stable for the median and central 68% interval in this tested case; a finer grid is preferable when reporting this case's 95% upper endpoint to hundredths or finer precision. This is a targeted example, not a universal error bound across all observations.

### 3. Widening the grid while holding the prior fixed is not a prior sensitivity

The artifact's `wider_grid_same_prior` case (grid 30–110, prior still 50–90) reproduces the finer baseline posterior endpoints to floating-point precision. By contrast, `wider_grid_wider_prior` changes the actual prior support to 30–110 and changes the posterior median and interval substantially. These are different operations: enlarging the computational grid outside a fixed prior should not change the posterior, whereas enlarging the prior support is a genuine modelling sensitivity.

## Reporting recommendations

1. Keep the computational grid wider than the prior support and normalize only over the supported prior interval.
2. For final tables, avoid implying excessive precision for tail quantiles. If 95% endpoints are central to a claim, compare at least 4,001, 16,001, and 64,001 grid points on representative edge and interior cases.
3. Treat the single-observation refinement as a diagnostic, not proof of convergence for every posterior shape or the entire simulation matrix.
4. Keep numerical convergence, repeated-sampling coverage, prior sensitivity, and physical-model validity as separate evidence categories.
