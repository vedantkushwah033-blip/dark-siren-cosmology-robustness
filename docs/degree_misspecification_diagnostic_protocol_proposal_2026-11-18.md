# Protocol proposal: separate finite-validation uncertainty from inclusion-model misspecification

Date: 2026-11-18  
Status: **DESIGN PROPOSAL ONLY — NOT IMPLEMENTED, NOT PREREGISTERED, NOT RUN**

## Purpose

The current curvature pilot compares five density-reconstruction arms. Its estimated-propensity arms D and E fit a degree-one logistic inclusion model for every data-generating curvature value. At nonzero curvature this is deliberate functional-form misspecification. Arm E integrates coefficient uncertainty conditional on that degree-one model; it does not integrate over the omitted quadratic term.

A clean diagnostic is to add a correctly specified degree-two propensity-model pair, while retaining the existing five-arm experiment unchanged. This creates a controlled model-degree comparison and helps separate:
1. finite-validation uncertainty under a correctly specified inclusion model;
2. bias from fitting degree one when the true logit is quadratic;
3. variance/weight instability introduced by estimating an additional coefficient;
4. numerical integration error in the three-dimensional coefficient posterior.

This is a diagnostic experiment, not a claim that degree two is universally preferable or that the true inclusion model would be known in observational applications.

## Exact model relationship

The synthetic truth is
[
\operatorname{logit}\pi(z)
=\alpha_\gamma+\beta x+\gamma(x^2-c_g),
\qquad x=(z-0.205)/0.195,
\]
where (c_g=E_g[x^2]) under the declared parent measure.

The fitted degree-two polynomial basis is
[
\operatorname{logit}\pi_2(z)=\theta_0+\theta_1x+\theta_2x^2.
]
The truth is exactly in this family, with
[
(\theta_0,\theta_1,\theta_2)
=(\alpha_\gamma-\gamma c_g,\beta,\gamma).
]
Thus degree two is correctly specified for all seven gamma cells, while degree one is correctly specified only at gamma=0. This is a statement about the synthetic DGP, not real survey selection.

The current posterior implementation already accepts degree 1 or 2, uses a proper Gaussian prior, and supports tensor Gauss-Hermite integration. The density runner currently hard-codes `degree=1`, so adding degree-two arms requires an explicit runner/auditor extension; it is not a configuration-only change.

## Proposed arm structure

Preserve A-C exactly and split the estimated-propensity arms by fitted model degree:

| Arm | Inclusion model | Point / uncertainty treatment | Interpretation |
|---|---|---|---|
| A | none | Catalogue-only | Incomplete-catalogue baseline |
| B | oracle parent | Full parent population | Diagnostic parent reference |
| C | true inclusion probabilities | Known-probability IPW | Simulation oracle-weight reference |
| D1 | degree-one logistic | Posterior mode plug-in IPW | Current misspecified MAP arm when gamma != 0 |
| E1 | degree-one logistic | Integrate density over coefficient posterior | Current coefficient-uncertainty arm |
| D2 | degree-two logistic | Posterior mode plug-in IPW | Correctly specified MAP arm under this DGP |
| E2 | degree-two logistic | Integrate density over coefficient posterior | Correctly specified coefficient-uncertainty arm |

This is a seven-arm diagnostic extension. Do not relabel D2/E2 as new estimators: they are the same plug-in and posterior-integrated IPW constructions with a different propensity-model basis.

For gamma=0, degree two contains an unnecessary quadratic coefficient. Its performance is informative about the finite-sample variance cost of adding a redundant term; it should not be expected to dominate degree one.

## Data and pairing

- Retain the existing seven gamma values, parent population, rate-preserving intercept calibration, validation-frame construction, nested validation sizes, common random-number pairing, and all raw-input retention.
- For every replicate and validation size, fit degree one and degree two to exactly the same observed validation rows and labels.
- Do not change the existing five-arm run or reinterpret its results. The seven-arm extension should have its own protocol identifier and output schema.
- Keep the current 20-replicate campaign as a numerical/engineering pilot only. It is not sufficient for confirmatory estimator ranking or narrow coverage claims.
- Preserve every planned attempt and explicit failure status. Never silently replace failed replicates.

## Validation outcomes to record

### 1. Propensity prediction (distinct from density recovery)

The validation frame is generated independently of the analysis parent population. Within that frame, records not selected into the fitting subset can serve as a held-out predictive set, provided their labels were generated by the same declared DGP and they are not used in fitting or model-degree choice.

For each fitted degree and validation size, record:
- held-out Bernoulli log score / negative log likelihood;
- held-out Brier score;
- calibration intercept and slope from a separately declared diagnostic regression;
- reliability-bin counts and observed-versus-predicted inclusion rates;
- predictive-probability range and any numerical saturation.

Use the full held-out frame only for evaluation. Do not select model degree, prior, or quadrature order based on held-out scores and then report the same scores as unbiased evaluation. If model selection is a goal, introduce a separate training/selection split and a final untouched test frame.

### 2. Weight stability

For D1/E1 and D2/E2, retain untrimmed:
- Kish ESS and entropy ESS;
- maximum normalized weight;
- top 1% and 5% weight mass;
- support/positivity diagnostics;
- node-specific diagnostics for posterior-integrated arms;
- quadrature ESS and maximum normalized quadrature mass.

No clipping, truncation, winsorization, or silent regularization should be introduced in this diagnostic extension. Any stabilization variant must be a separate, explicitly named arm with its own estimand and bias analysis.

### 3. Density reconstruction

Retain the existing density outcomes:
- IAE as the principal density loss;
- ISE and boundary IAE as secondary losses;
- posterior-mean density loss and posterior expected node loss as separate E-arm summaries.

The key contrasts are paired within replicate, validation size, gamma, and fixed bandwidth:
- D1 minus D2; E1 minus E2;
- D1 minus C; D2 minus C;
- E1 minus D1; E2 minus D2;
- each estimated arm versus the gamma-zero degree-one reference where scientifically meaningful.

Treat the 11-width grid as a sensitivity surface until a separate disjoint-replicate bandwidth selection/holdout protocol is frozen. Do not select the minimum width from the same replicates used to estimate its performance.

## Numerical requirements before execution

1. Extend the single-replicate runner to emit D1/E1 and D2/E2 separately, preserving coefficient nodes, quadrature weights, raw node weights, posterior summaries, and all density vectors.
2. Extend the independent raw-input auditor with its own degree-two posterior reconstruction. It must not call the production fitter or reuse its posterior nodes. Recompute the degree-two design matrix, proper-prior target, mode, Hessian, proposal, quadrature nodes and importance weights independently.
3. Verify degree-two posterior quadrature against a denser or otherwise independent reference on fixtures covering gamma=0, positive/negative curvature, n=100, n=300, n=1000, near-separation and complete separation. A proper prior keeps the posterior proper but does not guarantee a low-order quadrature approximation is accurate.
4. Verify the true-parameter mapping above and independently reconstruct the true inclusion probabilities from raw redshifts and the calibrated DGP.
5. Ensure D1/E1 and D2/E2 use identical catalogue rows, validation records, base-population weights, KDE grid and bandwidth for each paired comparison.
6. Add adversarial tests for degree-label swaps, missing coefficient nodes, changed prior scales, altered held-out IDs, row-order changes, missing lifecycle cells, and tampered posterior-weight vectors.
7. Preserve exact dependency and environment metadata, seed schedules, configuration hashes, raw-file checksums, and the complete failure ledger.
8. Run exact-head CI before any experiment. Only then run a small engineering smoke, independently audit it, and only then consider the seven-gamma pilot.

## Statistical interpretation

- A D1/E1 versus D2/E2 contrast at gamma != 0 changes both model bias and coefficient dimension. This is the intended bias-variance comparison, but it is not a pure one-factor experiment.
- At gamma=0, degree two is overparameterized. Its comparison with degree one estimates the finite-sample cost of an unnecessary term under the declared prior and design.
- E1 versus D1 measures coefficient uncertainty conditional on a linear model; E2 versus D2 measures coefficient uncertainty conditional on a quadratic model. Neither contrast alone measures model uncertainty.
- Held-out propensity prediction, density IAE, and eventual H0 calibration are distinct outcomes. A better held-out Brier score does not automatically imply lower density IAE, and lower density IAE does not establish calibrated H0 posteriors.
- The oracle arms B/C remain unavailable in practice and are used only as simulation diagnostics.
- A degree-two fit matching the true DGP does not establish that real catalogue selection is quadratic. The result is conditional on this controlled synthetic design.

## Stop/go gates

**GO to engineering implementation only if:**
- the existing five-arm protocol and outputs remain unchanged;
- the seven-arm schema and contrasts are frozen before examining new results;
- independent degree-two posterior auditing is implemented and tested;
- predictive holdout membership and data-use boundaries are unambiguous.

**GO to pilot execution only if:**
- exact-head CI passes;
- degree-two quadrature convergence checks pass;
- a small end-to-end artifact is independently reconstructed from raw inputs;
- failure accounting and output schema tests pass.

**NO-GO for H0 propagation until:**
- the density experiment is complete and independently audited;
- bandwidth handling is frozen by disjoint training/holdout replicate blocks;
- selection-conditioned likelihood and catalogue-inclusion corrections remain separately defined;
- grid/prior convergence and repeated-sampling H0 calibration plans are preregistered.

## Current status

Nothing in this document has been implemented or run. The existing curvature workflow remains the original five-arm, degree-one D/E density-only pilot. This proposal is not an amendment to that workflow and does not authorize a new experiment.
